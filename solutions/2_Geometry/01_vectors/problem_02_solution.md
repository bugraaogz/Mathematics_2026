## Question

The points are $A=(1,2,3)$ and $B=(4,-2,6)$.

1. Construct $\overrightarrow{AB}$.
2. Compute its length.
3. Compute the distance between the points using the coordinate formula.
4. Explain why both calculations give the same result.

## Solution

1. Vector $\overrightarrow{AB}$:
$$\overrightarrow{AB} = B - A = (4-1, -2-2, 6-3) = (3, -4, 3)$$

2. Length of $\overrightarrow{AB}$:
$$\|\overrightarrow{AB}\| = \sqrt{3^2 + (-4)^2 + 3^2} = \sqrt{9 + 16 + 9} = \sqrt{34}$$

3. Distance between $A$ and $B$:
$$d(A,B) = \sqrt{(4-1)^2 + (-2-2)^2 + (6-3)^2} = \sqrt{9 + 16 + 9} = \sqrt{34}$$

4. Both calculations yield the exact same result because the components of vector $\overrightarrow{AB}$ are precisely the coordinate differences $(x_B-x_A, y_B-y_A, z_B-z_A)$. Thus, calculating vector magnitude $\|\overrightarrow{AB}\|$ is mathematically identical to applying the Euclidean distance formula between points $A$ and $B$.
