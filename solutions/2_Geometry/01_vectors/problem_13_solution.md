## Question

Given $A=(0,0,0)$, $B=(1,2,0)$, $C=(0,1,1)$, $D=(2,5,1)$.

1. Construct $\overrightarrow{AB}$ and $\overrightarrow{AC}$.
2. Find $n=\overrightarrow{AB}\times\overrightarrow{AC}$.
3. Construct $\overrightarrow{AD}$ and check whether $\overrightarrow{AD}\cdot n=0$.
4. Based on this, decide whether $D$ lies in the plane determined by $A,B,C$, and justify the criterion.

## Solution

1. Vectors $\overrightarrow{AB} = (1,2,0)$ and $\overrightarrow{AC} = (0,1,1)$.

2. Normal vector $n$:
$$n = \overrightarrow{AB} \times \overrightarrow{AC} = (2(1)-0(1),\, 0(0)-1(1),\, 1(1)-2(0)) = (2, -1, 1)$$

3. Vector $\overrightarrow{AD} = (2,5,1)$ and dot product:
$$\overrightarrow{AD} \cdot n = 2(2) + 5(-1) + 1(1) = 4 - 5 + 1 = 0$$

4. Decision: Since $\overrightarrow{AD} \cdot n = 0$, vector $\overrightarrow{AD}$ is orthogonal to plane normal $n$, proving point $D$ lies in the plane determined by $A, B, C$.
